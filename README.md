# EEYES PRO - കംപ്ലീറ്റ് മൊബൈൽ ആപ്ലിക്കേഷൻ (Android & iOS)
### E.S TRADING COMPANY - Complete Cross-Platform Mobile ERP Application

---

## 🌟 ആമുഖം (Overview)

ഇഎസ് പ്രോ (EEYES PRO) ഇആർപി സോഫ്റ്റ്‌വെയറിന്റെ സമ്പൂർണ്ണ മൊബൈൽ ആപ്ലിക്കേഷനാണ് ഈ പ്രൊജക്റ്റ്. ആൻഡ്രോയിഡ് (Android), ഐഒഎസ് (iOS - iPhone/iPad) എന്നിവയിൽ പൂർണ്ണമായും ഉപയോഗിക്കാൻ സാധിക്കുന്ന വിധത്തിൽ modern touch UI, safe-area-inset, bottom navigation, instant camera barcode scanner, native UPI intent deep-linking, bilingual (മലയാളം & English) സപ്പോർട്ട്, offline-first IndexedDB സിങ്ക് എന്നിവ ഉൾപ്പെടുത്തിയാണ് ഇത് നിർമ്മിച്ചിരിക്കുന്നത്.

---

## 📱 പ്രധാന ഫീച്ചറുകൾ (Key Mobile Features)

1. **ഡാഷ്‌ബോർഡ് (Live Dashboard & KPIs)**:
   - ഇന്നത്തെ ആകെ സെയിൽസ് (Today's Sales ₹), പർച്ചേസ് ഇൻവേർഡ് (Inward Purchases ₹), കസ്റ്റമർ ബാക്കി (Receivables / ഉദ്ധാർ ₹), കൈവശമുള്ള പണം (Cash in Hand ₹).
   - 4 ക്വിക്ക് ആക്ഷൻ ബട്ടണുകൾ: ⚡ New Sale, 📷 Scan Barcode, 👥 Add Party, 💰 Collect Pay.
   - സ്റ്റോക്ക് കുറവുള്ള ഇനങ്ങൾക്കുള്ള ലൈവ് അലേർട്ടുകൾ (Low Stock Alerts) & റീ-ഓർഡർ ബട്ടൺ.

2. **മൊബൈൽ പിഒഎസ് & സെയിൽസ് ബില്ലിംഗ് (Mobile Billing)**:
   - മൊബൈലിൽ അതിവേഗം കസ്റ്റമർ സെയിൽസ് ബിൽ തയ്യാറാക്കൽ.
   - സ്മാർട്ട്ഫോൺ ക്യാമറ ഉപയോഗിച്ച് ഉൽപ്പന്നങ്ങളുടെ ബാർകോഡ് സ്കാൻ ചെയ്തു കാർട്ടിലേക്ക് ചേർക്കുക.
   - ജിഎസ്ടി (CGST/SGST/IGST), കിഴിവ് (Discount) ഓട്ടോമാറ്റിക് കണക്കുകൂട്ടൽ.
   - ക്യാഷ്, യുപിഐ (UPI), ഉദ്ധാർ (Credit) പേയ്മെന്റ് മോഡുകൾ.
   - വാട്സാപ്പ് (WhatsApp) വഴി ബില്ലും രസീതും ഒറ്റ ക്ലിക്കിൽ ഷെയർ ചെയ്യൽ (`https://wa.me/...`).

3. **ഇൻസ്റ്റന്റ് യുപിഐ പേയ്മെന്റുകൾ (Instant UPI & QR Code)**:
   - ബിൽ തുകയ്ക്കുള്ള ഡൈനാമിക് യുപിഐ ക്യുആർ കോഡ് (`upi://pay?pa=estrading@sbi...`).
   - ഗൂഗിൾ പേ (GPay), ഫോൺപേ (PhonePe), പേടിഎം (Paytm), ഭീം (BHIM) എന്നീ ആപ്പുകളിലേക്ക് നേരിട്ട് തുറക്കുന്ന ഡീപ് ലിങ്കുകൾ (Android & iOS Native Intent).

4. **ഇൻവെന്ററി & സ്റ്റോക്ക് കൺവേർഷൻ (Inventory & Stock Conversion)**:
   - സ്റ്റോക്ക് ലെവൽ, വില (MRP, Sale Rate, Purchase Rate), ബാർകോഡ് സെർച്ച്.
   - **Bulk-to-Loose Conversion Calculator**: അജ്വ അരി ചാക്ക് (50kg Sack - ₹2,500) പൊട്ടിച്ച് ലൂസ് കിലോഗ്രാമാക്കുമ്പോൾ വരുന്ന സ്വാഭാവിക തൂക്കക്കുറവ് (Wastage Recalculation e.g., 0.80kg loss) കിഴിച്ച് പുതിയ കോസ്റ്റ് വില (True Cost ₹50.81/kg) കൃത്യമായി സ്റ്റോക്കിൽ രേഖപ്പെടുത്തൽ.

5. **പാർട്ടികൾ & ഖാത ലെഡ്ജർ (Parties Khata & Balances)**:
   - കസ്റ്റമർ, സപ്ലയർ ലിസ്റ്റ്, ബാക്കി തുക (Balance Due).
   - നേരിട്ടുള്ള ഫോൺ കോൾ (`tel:...`), വാട്സാപ്പ് ലെഡ്ജർ സ്റ്റേറ്റ്മെന്റ് & പേയ്മെന്റ് റിമൈൻഡർ ലിങ്ക്.
   - പേയ്മെന്റ് കളക്ഷൻ റെക്കോർഡിംഗ്.

6. **സെയിൽസ്മാൻ ഫീൽഡ് ട്രാക്കർ (Salesman GPS Tracker)**:
   - ഫീൽഡ് സെയിൽസ്മാൻമാരുടെ ജിപിഎസ് ലൊക്കേഷൻ ചെക്ക്-ഇൻ, ഓർഡർ ബുക്കിംഗ്, കളക്ഷൻ ലോഗ്.

7. **ഓഫ്‌ലൈൻ റീസൈലൻസ് & ഡെസ്ക്ടോപ്പ് സിങ്ക് (Offline-First Sync)**:
   - ഇന്റർനെറ്റ് അല്ലെങ്കിൽ സ്റ്റോർ വൈ-ഫൈ ഇല്ലാത്തപ്പോഴും മൊബൈൽ ആപ്പ് സുഗമമായി പ്രവർത്തിക്കും.
   - ഇൻ-മെമ്മറി ക്യൂ വഴി ഡാറ്റ സൂക്ഷിക്കുകയും, കമ്പ്യൂട്ടറിലെ EEYES PRO ഡെസ്ക്ടോപ്പ് സെർവറുമായി (`http://localhost:3000` അല്ലെങ്കിൽ ലോക്കൽ ഐപി) കണക്റ്റ് ആകുമ്പോൾ ഓട്ടോമാറ്റിക്കായി സിങ്ക് ചെയ്യുകയും ചെയ്യുന്നു.

8. **ദ്വിഭാഷാ സംവിധാനം (Bilingual Malayalam & English)**:
   - പൂർണ്ണമായും മലയാളത്തിലും ഇംഗ്ലീഷിലും ഒറ്റ ക്ലിക്കിൽ ഭാഷ മാറ്റാനുള്ള സ്വിച്ചർ.

```
    ├── manifest.json           # Standalone PWA Manifest (Icons, Theme, Shortcuts)
    ├── sw.js                   # Offline Service Worker
    ├── css/
    │   └── mobile.css          # iOS/Android Safe Area, Bottom Nav, Animations
    ├── icons/                  # 192x192, 512x512 App Icons
    └── js/
        ├── app.js              # Tab Router & Master Controller
        ├── api.js              # Desktop Server Connector & Sync Engine

        ├── billing.js          # Mobile POS & Invoicing

        ├── scanner.js          # Camera Barcode Scanner
        └── salesman.js         # Salesman GPS Tracker
```

## 🚀 ആപ്പ് റൺ ചെയ്യുന്ന വിധം (How to Run & Test)

### 1. കമ്പ്യൂട്ടറിൽ ലോഞ്ച് ചെയ്യാൻ:
- `eeyes-pro-mobile` ഫോൾഡറിലെ `start_mobile.bat` ഡബിൾ ക്ലിക്ക് ചെയ്യുക (അല്ലെങ്കിൽ PowerShell-ൽ `.\start_mobile.ps1` റൺ ചെയ്യുക).
- ഇത് നിങ്ങളുടെ ബ്രൗസറിൽ `http://localhost:3001` ഓപ്പൺ ചെയ്യും.
- മൊബൈൽ വ്യൂ കാണാൻ ബ്രൗസറിൽ `F12` അമർത്തി **Device Toggle (Ctrl+Shift+M)** ക്ലിക്ക് ചെയ്ത് iPhone 14 Pro അല്ലെങ്കിൽ Pixel 7 തിരഞ്ഞെടുക്കുക.

## 📲 ആൻഡ്രോയിഡ് ഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യാൻ (Android Setup)

### മാർഗ്ഗം 1: ഇൻസ്റ്റന്റ് പിഡബ്ല്യുഎ (Instant Mobile App Install - PWA)
1. നിങ്ങളുടെ കമ്പ്യൂട്ടറും ആൻഡ്രോയിഡ് ഫോണും ഒരേ വൈ-ഫൈ (Wi-Fi) നെറ്റ്‌വർക്കിൽ കണക്റ്റ് ചെയ്യുക.
2. ടെർമിനലിൽ കാണിക്കുന്ന ഐപി വിലാസം (ഉദാഹരണത്തിന്: `http://192.168.1.xxx:3001`) മൊബൈൽ Chrome ബ്രൗസറിൽ ഓപ്പൺ ചെയ്യുക.
3. Chrome മെനുവിൽ (മൂന്ന് കുത്തുകൾ) ക്ലിക്ക് ചെയ്ത് **"Install App"** അല്ലെങ്കിൽ **"Add to Home Screen"** തിരഞ്ഞെടുക്കുക.
4. ആപ്പ് നിങ്ങളുടെ ആൻഡ്രോയിഡ് ഫോണിന്റെ ഹോം സ്ക്രീനിൽ യഥാർത്ഥ നേറ്റീവ് ആപ്ലിക്കേഷനായി ഇൻസ്റ്റാൾ ആകും!

### മാർഗ്ഗം 2: നേറ്റീവ് എപികെ (Native APK via Android Studio)
```bash
cd eeyes-pro-mobile
npx @capacitor/cli sync android
npx @capacitor/cli open android
```
- Android Studio തുറന്ന ശേഷം **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** ക്ലിക്ക് ചെയ്താൽ ഇൻസ്റ്റാൾ ചെയ്യാവുന്ന `.apk` ഫയൽ ലഭിക്കും.

## 🍏 ഐഫോണിൽ ഇൻസ്റ്റാൾ ചെയ്യാൻ (iOS iPhone Setup)

### മാർഗ്ഗം 1: ഇൻസ്റ്റന്റ് ആപ്പിൾ പിഡബ്ല്യുഎ (Safari Add to Home Screen)
1. കമ്പ്യൂട്ടറും ഐഫോണും ഒരേ വൈ-ഫൈയിൽ കണക്റ്റ് ചെയ്യുക.
2. ഐഫോണിലെ **Safari** ബ്രൗസർ തുറന്ന് `http://192.168.1.xxx:3001` ടൈപ്പ് ചെയ്യുക.
3. സഫാരിയുടെ താഴെയുള്ള **Share ബട്ടൺ (ചതുരത്തിൽ മുകളിലേക്ക് അമ്പടയാളമുള്ള ഐക്കൺ)** അമർത്തുക.
4. ലിസ്റ്റിൽ താഴേക്ക് സ്ക്രോൾ ചെയ്ത് **"Add to Home Screen"** അമർത്തുക.
5. ഇപ്പോൾ ഐഫോൺ ഹോം സ്ക്രീനിൽ EEYES PRO ആപ്പ് ഐക്കൺ വരികയും, ക്ലിക്ക് ചെയ്യുമ്പോൾ സഫാരി ബാറുകൾ ഇല്ലാതെ ഫുൾ സ്ക്രീൻ നേറ്റീവ് ആപ്പായി പ്രവർത്തിക്കുകയും ചെയ്യും!

### മാർഗ്ഗം 2: നേറ്റീവ് ഐഒഎസ് ആപ്പ് (Xcode Build)
```bash
cd eeyes-pro-mobile
npx @capacitor/cli sync ios
npx @capacitor/cli open ios
```
- Xcode തുറന്ന് നിങ്ങളുടെ ആപ്പിൾ ഡെവലപ്പർ അക്കൗണ്ട് സെലക്റ്റ് ചെയ്ത് iPhone-ലേക്ക് നേരിട്ട് റൺ ചെയ്യാം.
